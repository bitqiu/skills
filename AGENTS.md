# Repository Purpose
A maintainable Product Engineering Skills Repository.

# Core Principles
Single Responsibility, reuse upstream skills, and explicit lifecycle boundaries.

# Skill Discovery
Use the flat `skills/` namespace and registry metadata.

# Lifecycle Routing
Product → UX → Design → Figma → Frontend → QA.

# Workflow Routing
Use the workflows for orchestration; skills perform one transformation.

# Validation Requirement
Run `./scripts/validate-skills.sh` before shipping changes. Custom skills must be created, reviewed, and optimized with `skill-creator`.
